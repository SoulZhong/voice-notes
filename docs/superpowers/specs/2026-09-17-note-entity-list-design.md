# 笔记页关键实体列表(可编辑)设计

2026-09-17 grilling 定稿。功能:每篇笔记展示提取出的关键实体清单,用户可编辑;
与既有实体抽取管线(Aing 捆绑产出)和全局知识图谱(纯派生 + 治理账本)衔接。

## 领域模型(本设计的语汇)

- **实体(Entity)**:本篇 `aing.json.entities` 中的一条(id `ent_N`/`P<n>`、kind、name、aliases)。
  真值在每篇 aing.json;全局图谱 `graph.sqlite` 由各篇派生重建,治理账本
  `knowledge-overrides.json` 在其上叠加(改名/合并/别名)。
- **提及(Mention)**:段落内 char 半开区间,指向本篇实体 id。正文高亮与联动的锚。
- **本篇操作 / 全局操作**:写 aing.json(重建自然传播)vs 写治理账本(跨笔记生效)。

## 决策记录

| # | 决策 | 选择 |

| Q1 | 位置形态 | 说话人条下方同形态 chips 行;超行收「+N」;点 chip 开浮层编辑 |
| Q2 | 类型范围 | 人、公司/组织、产品/项目 + 术语/概念;不收金额/日期(属摘要职责) |
| Q3 | 操作集 | 删除、改名、新增、改类型、合并——五项全要 |
| Q4/Q8 | 作用域矩阵 | 删除=仅本篇;新增=仅本篇(重建自动进全局);改名=本篇+全局账本 RenameEntity;合并=全局(复用图谱 merge);改类型=仅本篇(重建传播) |
| Q5 | 正文联动 | 点实体→滚到首个提及并高亮全部提及;再点跳下一处 |
| Q6 | 导出 | MD 导出标题后加「关键实体」一节 |
| Q7 | 无 Aing 笔记 | 整行隐藏(实体依附修订稿);partial/failed 照常显示已抽到的 |

## 关键实现约定

- **改名不丢高亮**:旧名自动转为别名保留,提及区间不动(正文原文仍是旧写法)。
  改名双写:本篇 aing.json(name+alias)+ 全局账本 RenameEntity(经 ent_N→kg_ 解析)。
- **新增自动找提及**:按名字在修订稿正文搜提及(复用 compute_mentions);搜不到
  也保留在列表。
- **每次本篇实体写操作后排队全局重建**(queue_knowledge_rebuild),与治理操作同款。
- **删除的引用完整性**:删除实体时,其提及与以它为端点的本篇 relations 一并移除。
- 排序:提及数降序;类型色标沿用侧栏全局实体列表的 kind 配色。
- 正文编辑器的 mentions 重建沿用既有 live-mentions 机制,实体表变更后整份重放修订稿
  (与说话人徽章刷新同款签名比对纪律)。

## 分期

- 一期:后端本篇实体 CRUD 命令 + chips 行 + 浮层(删/改名/增/改类型)+ 正文联动 + 导出节
- 二期:合并(浮层内选目标,复用全局 merge)+ 与图谱治理页的互跳
