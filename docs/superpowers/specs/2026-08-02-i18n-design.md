# 多语言(i18n)设计 — 中/英全界面支持

日期:2026-08-02。目标:系统支持多语言,初步支持中文与英文,覆盖所有界面与功能。

## 现状

- 前端 SvelteKit + Svelte 5 runes,无任何 i18n 库;30 个 `.svelte` + 27 个非测试 `.ts` 含硬编码中文(约 2300 行 Svelte + 476 行 TS,其中 40-60% 为真实用户可见文案,其余是注释)。
- 后端 Tauri 2 + Rust:托盘菜单 4 条标签;经 invoke 冒泡到前端的中文错误约 438 条(lib.rs 顶层命令约 92 条,深层模块 anyhow 链约 340 条);无系统通知、无原生对话框文案(对话框文案都在前端)、无主菜单。
- 设置持久化:`app_data_dir()/settings.json`,原子写,前端经 `get_settings`/`set_settings`;**无任何 UI 语言字段**。已有 `language_filter` 是转写乱码过滤,与 UI 语言无关,命名需避开。
- 日期格式化集中在 `src/lib/notes.ts`,仅 `formatDuration` 含中文;`personPick.ts` 硬编码拼音 collator。
- 陷阱:`models/download.rs` 用错误文案 `contains("大小不符")` 等做重试控制流(4 处),`lib.rs` 以 `msg == "cancelled"` 识别取消——翻译前必须先改为结构化判据。

## 方案选型

考虑三个方案:

1. **svelte-i18n / paraglide 等库**:带 ICU 复数、懒加载。代价:新增依赖与构建插件,ICU 能力本项目用不上(中英各一份、无复杂复数嵌套),paraglide 还要接管构建。
2. **手写轻量 i18n(选定)**:`$state` locale + `t(key, params)` 查表,字典为普通 TS 模块,`satisfies` 保证中英键齐平,零依赖、可 tree-shake、与现有 runes 单例模式(class + 导出单例)一致。离线桌面应用两种语言全量打包,无需懒加载。
3. **仅英文化(替换为英文)**:不满足"多语言"目标,排除。

Rust 侧同理不引依赖:`tr!(zh_fmt, en_fmt, args…)` 宏按全局 locale 选格式串,`sys-locale` crate(零依赖)解析"跟随系统"。

## 架构

### 设置字段

- Rust `Settings` 新增 `ui_lang: String`,serde 默认 `"system"`;取值 `"system" | "zh" | "en"`。
- 前端 `models.ts` 的 `Settings` 类型同步加 `ui_lang: string`。
- 解析规则(两端一致):`system` → 系统 locale 以 `zh` 开头则中文,否则英文。前端用 `navigator.language`,Rust 用 `sys_locale::get_locale()`。

### 前端核心 `src/lib/i18n/`

```
src/lib/i18n/
  index.svelte.ts   # I18n 类单例:locale = $state;t();setLocale();initFromSettings()
  dict/
    shell.ts        # 每个领域分片一个模块,导出 { zh: {...}, en: {...} }
    settings.ts     # en 用 satisfies Record<keyof typeof zh, Msg> 编译期对齐键
    notes.ts
    record.ts
    graph.ts
    speakers.ts
    ai.ts
```

- 字典值类型 `Msg = string | ((p: Record<string, unknown>) => string)`:静态文案用字符串(支持 `{name}` 占位插值),英文复数等特殊形态用函数。
- `t(key, params?)`:按当前 locale 从合并字典查;缺键返回 key 并 `console.warn`(开发期可见,护栏测试兜底)。`t` 内部读 `i18n.locale`($state),模板表达式随语言切换自动重渲。
- key 命名:`<领域>.<组件/块>.<语义>`,如 `settings.theme.label`。
- 生效:`+layout.svelte` 挂载时与 `applyTheme` 并列调用 `i18n.initFromSettings(s)`;同时设 `document.documentElement.lang`。
- 语言切换即时生效(无需重启):Svelte 端响应式重渲;Rust 端见下。
- `personPick.ts` collator 改为按 locale 取(`zh` 用拼音序,`en` 用默认序);`notes.ts` 的 `formatDuration`、兜底名(未命名/我/对方/说话人 N)走字典。日期 `formatDate` 保持 ISO 风格不动。

### 设置页 UI

「通用」分组「外观」行正下方新增「语言 / Language」行,复用 `.seg` 分段控件(跟随系统 / 中文 / English),沿用 `saveSetting` 套路:写设置成功后调 `i18n.setLocale`。**不放**「录制」分组,避免与「乱码过滤」混淆。

### Rust 侧

- 新模块 `src-tauri/src/i18n.rs`:`AtomicBool` 存"当前是否英文",`init(app)` 启动时从 settings 解析,`set_lang(&str)` 更新;`tr!` 宏(`macro_rules!`)按其选 `format!` 分支。
- `tray.rs` 的 4 条菜单标签查 `tr!`;`set_settings` 中仿照 `tray_changed` 增加 `lang_changed` 判定,变化时 `i18n::set_lang` 并触发现成的托盘重建路径(菜单项 id 稳定,事件分发不受影响)。
- 错误文案分层:
  - **本次翻译**:顶层用户可见错误——lib.rs 全部 `#[tauri::command]` 内的中文 Err(~92 条)、player.rs、shortcuts.rs、update.rs、models/download.rs。
  - **前置重构**:download.rs 的 4 处 `contains(文案)` 重试判据改为结构化错误(枚举或错误码字符串常量),`msg == "cancelled"` 语义保持;之后才允许翻译这些文案。
  - **暂不翻译(记为后续)**:深层模块 anyhow 上下文(~340 条,作为技术细节拼接在已翻译前缀之后展示)、MCP 工具描述/返回(~220 条,面向 AI 助手)、CLI println(~30 条,终端向)、日志 eprintln。

### 前端错误前缀

`保存失败: ${e}` 类前缀全部走字典(`common.saveFailed` 等通用键 + 领域特有键);`${e}` 原样拼接。

## 覆盖率护栏

新增 `src/lib/i18n/noHardcodedCjk.test.ts`(vitest, node 环境):

- 扫描 `src/**/*.{svelte,ts}`,剥离注释(`//`、`/* */`、`<!-- -->`)后检测 CJK 字符。
- 允许清单:`src/lib/i18n/dict/**`、`*.test.ts`。
- 命中即 fail 并列出文件行号——保证现在清零、未来新增文案必须进字典。

## 测试策略

- 现有断言中文文案的测试:改为从 zh 字典取值断言(测试默认 locale=zh),不硬编码。
- i18n 核心单测:插值、函数值、缺键回退、locale 解析(system/zh/en)。
- `cargo check` + 全量 `vitest` + `svelte-check` 全绿为完成线。
- 真机冒烟(记录清单,延续项目惯例):切换语言后设置页/侧栏/托盘即时变化、重启后保持、system 跟随。

## 实施顺序

1. 核心:settings 字段(Rust+TS)+ `src/lib/i18n/` + 设置页语言行 + layout 初始化。
2. 前端提取,7 个并行分片(各分片独占源文件+字典分片,零交集):
   A settings 页+update.ts;B notes 详情+editor;C record 页+recording 相关;D graph 全家(ForceGraph/治理/关系);E speakers 两页+tidy/people;F shell(Sidebar/layout/首页/Welcome/ContextGuide/onboarding);G ai 两页+hooks 两页+ailog+ModelDownloadCard+杂项 ts。
3. Rust:download.rs 错误码重构 → i18n.rs + tray + 顶层错误翻译。
4. 护栏测试补齐 + 全量验证。

## 明确不做(YAGNI)

- 不引 i18n 库、不做 ICU MessageFormat、不做语言包懒加载。
- 不翻译代码注释、日志、DESIGN/docs 文档。
- 初版不加第三语言,但字典结构天然可扩展。
