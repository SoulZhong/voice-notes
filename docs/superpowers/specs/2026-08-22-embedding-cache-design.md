# 段落声纹缓存:算过一次,永不重算

日期:2026-08-22 · 状态:用户拍板("存下来声纹要做")

## 问题

每段语音的声音指纹(192 维向量)在三个地方被反复从音频现算:实时录音(算完即丢)、
每次 Aing 的重聚类统计、每次「这不是一个人?」拆分。80 分钟大簇实测 724 段 ×
数百毫秒 = 一次点击等数分钟(2026-08-22 用户实测)。

## 方案:笔记级写通缓存(offline 路径)

- **文件**:`notes/<id>/embeddings.json`
  `{ schema_version, model, entries: [{seq, start_ms, end_ms, source, vec}] }`
  724 段约 1.2MB,可整删(纯缓存,丢了就重算)。
- **键与失效**:命中要求 (seq, start_ms, end_ms, source) 与当前段**完全一致**且
  model 与当前声纹模型一致。凡影响切片的变更(重转写换段、时基重投影、换模型)
  自动失效,不需要显式失效逻辑。
- **写通**:embed_all(重聚类统计与拆分分组共用的唯一入口)读缓存→只算缺的→
  原子写回(tmp+rename),条目修剪到当前段集合。并发由既有 FEEDBACK_GATE 序列化
  (两个调用方都持它);读损坏 = 当无缓存。
- **效果**:第一次 Aing 付一次全款,此后拆分/重 Aing 的嵌入段秒出(含进度条快进)。

## 明确不做(本期)

- **实时侧写入**:录音时 registry 算的向量窗口与 embed_all 的切片口径不同
  (自有缓冲 vs 轨道毫米切片),混写两种口径会污染缓存语义;且要过 writer 独占
  与崩溃一致性。留作后续(届时需统一口径或分 namespace)。

## 测试

- 命中跳过嵌入(mock embedder 计数);model 不符全量失效;段边界变更单段失效;
  写回修剪(消失的 seq 不留);读损坏文件 = 重算不崩。
