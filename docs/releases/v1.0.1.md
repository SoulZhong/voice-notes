# v1.0.1 发布说明

小修版本：左侧竖排页签恢复「页签」的样子。

## 左侧页签更像页签

- 页签那一条比列表暗一档；选中的页签与列表同底、带细描边，右侧和列表连成一体，字也加粗——一眼看出当前在哪个页签。
- 未选中的页签退在暗处，鼠标移上去稍微亮起。
- 只改样式，布局不变。（#730 用户反馈「失去了页签的感觉」）

## 仓库清理

- 去掉误提交进仓库的 `node_modules` 快捷方式（指向开发机临时目录），`.gitignore` 同时改为也忽略这类快捷方式。

## 发布步骤（留档）

1. `git tag v1.0.1 && git push origin v1.0.1` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
2. `gh release edit v1.0.1 --notes-file docs/releases/v1.0.1.md --title "v1.0.1 · 左侧页签恢复页签样式" --draft=false --latest`。
3. 真机冒烟：
   - 从 1.0.0 一键升级到 1.0.1。
   - 宽窗、窄窗，浅色、深色下看左侧页签：选中项清楚、和列表相连。
