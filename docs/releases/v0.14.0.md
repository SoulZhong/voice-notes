# v0.14.0 发布说明

v0.13.1 之后 4 个 PR:声纹库改成"样本说了算",会议搭子能逐份审样本,试听所见即所存;一键更新终于走系统代理。

## 声纹库:一个人的声纹 = 他的样本,别无其他

- **单均值宪法**:入库/纠错回灌不再往档案里堆"会话变体";合并不继承对方旧质心,合并后按样本重建;识别种子只取主质心。此前一次误合并会在档案里留下一根永久的"认领触角",越用越像错的人(8/28 事故:用户本人被认成同事),从此没有这条路。
- **自动归并彻底停用**:整理页只出建议,不再自动落库。
- **认领差距门**:两个有名字的人相似度贴得太近(<0.03)时宁可不认,交给人判。
- 每人样本上限 10 → **30**;样本嵌入按内容哈希缓存,删一份样本只重算新样本。
- 识别方法新增第三档「多质心」(实验,默认关):样本攒够后按设备/场景聚出子声纹,命中任一即认人。

## 会议搭子:逐份审样本

- 人物页重设计:每份样本一行——试听、录制日期、**来源会议**(可点进笔记;老样本按时间推测并标注)、「归到别人」、删除。
- 删除/归到别人后立即响应,声纹重算与来源会议的说话人关联同步在后台进行并显示状态;笔记里改派/解除说话人,旧人从那簇截的样本自动退掉。
- 侧栏已命名的人按样本份数、最近样本时间倒序。

## 试听:所见即所存

- 说话人面板直接列出该人最长的 5 段(时间点、时长),点哪段听哪段,不再有"再点一次换下一段"的暗规则。
- 勾「作为样本」的段才入库(合计 ≥10 秒);不勾则用你最后听的那段。段内混杂/别人插话的段,「这段不是此人」一键拆成新说话人,不依赖聚类。
- 笔记页说话人条:修订稿与逐字稿同一份交互,AI 整理进行中照常可改名/选人。

## 其它

- **一键更新与全部出站 HTTP 走系统代理**(环境变量 → macOS 系统代理 → 直连,按目标分流并尊重绕过规则):Clash 等环境下更新清单能取到了(v0.13.1 冒烟实录)。
- devtools:`reidentify_eval`(按当前库重认最近几场,只读)、`speaker_loso_eval --multi / LOSO_SHOW_ABSTAIN=1`。

审库后实测:声纹库留一评测出手准确率 90.7% → 96.0%,召回 66.7% → 70.8%。
