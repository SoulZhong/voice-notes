# v0.21.2 发布说明

v0.21.1 之后 1 个 PR：修复了程序连开两三天后，合上 MacBook 再打开就崩溃的问题。

## 修复

- **合盖再打开不再崩溃**：以前开着设备听写、设备又不在身边时，程序每 10 秒左右重新找一次设备，每找一次就留下一个用不上的后台线程。连开两三天，这类线程会攒到一万六千多个，撞上 macOS 给单个程序的上限。之后一合盖再打开，系统让界面重新连上屏幕，这时程序已经要不到资源，只能退出。现在只在开始时取一次蓝牙，之后一直复用，线程数不再增长。（#260）

## 发布步骤（留档）

1. 发版前检查模型下载地址：`cargo test --manifest-path src-tauri/Cargo.toml --features devtools --lib -- --ignored every_registered_model_url_is_downloadable`。
2. `git tag v0.21.2 && git push origin v0.21.2` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
3. `gh release edit v0.21.2 --notes-file docs/releases/v0.21.2.md`，标题「v0.21.2 · 合盖再打开不再崩溃」。
4. 真机冒烟：
   - 从 0.21.1 一键升级。
   - 设备不在身边时让程序挂几个小时，用 `ps -M <pid> | wc -l` 看线程数，应保持在几十个上下、不持续上涨。
