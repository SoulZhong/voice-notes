# v1.0.2 发布说明

小修版本：录音时一口气不停顿讲话，也能及时出定稿、随时改说话人。

## 录音中连续讲话按 15 秒出定稿段

- 以前一口气讲一分钟不停顿，这一分钟都只有一大段斜体预览：越攒越长、挡住上面的内容，说话人标签也点不动（只有定稿段能改）。
- 现在一句话攒到约 15 秒，就在其中最安静的地方切一刀，前半截立刻成为定稿段，可以点说话人标签改人；预览最多几行。
- 实时字幕从切口接着往下走，上一段的尾巴不会在新预览里重复出现。
- 正常有停顿的对话，切段方式与以前一致。（#273）

## 发布步骤（留档）

1. 模型 URL 检查：`cargo test --features devtools --lib -- --ignored every_registered_model_url_is_downloadable`。
2. `git tag v1.0.2 && git push origin v1.0.2` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
3. `gh release edit v1.0.2 --notes-file docs/releases/v1.0.2.md --title "v1.0.2 · 连续讲话及时定稿" --draft=false --latest`。
4. 真机冒烟：
   - 从 1.0.1 一键升级到 1.0.2。
   - 录音中不停顿讲 1 分钟以上：约每 15 秒出一段定稿，可点说话人标签改人。
   - 暂停/继续、停止时最后一句不丢字。
