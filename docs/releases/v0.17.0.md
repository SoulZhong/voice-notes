# v0.17.0 发布说明

v0.16.0 之后 10 个 PR:与会人员进入识别链路,每篇笔记有了关键实体清单,听录音时随便逛。

## 与会人员:名单帮你认人

- **两条来源**:关联日程自动带入参会人;没日程的会议在头部手动输入(支持中英文逗号/分号/顿号批量粘贴)。
- **认人时自动匹配**:整份名单作为声纹识别的闭集先验——名单上的人优先匹配,邮箱精确命中的最优先;身份推断的 AI 也能看到名单做称呼配对。强先验不硬约束,临时加入者不误伤。
- **一键指认**:说话人浮层里名单排成胶囊,点名字即完成命名/关联;已用的名字打勾,还剩谁没认一眼看出。
- **企微日历的拼音邮箱能显示中文名**:日历名 > 库中邮箱命中 > 人名全拼比对(wangyuqi→王宇琪,zhenjie.yang 正倒序都试) > 前缀兜底;指认一次自动把邮箱记进人物档案,下次精确命中。
- **没到场的能删**:日历参会人标签点 × 隐藏,展示/指认/识别先验三处同步剔除,「已隐藏 n 位·恢复」一键找回。

## 关键实体:这场聊了谁、哪些事

- 说话人条下方新增实体行:人物/组织/产品项目/术语四类四色,按提及次数排序。
- 点实体定位正文提及(高亮全部,再点跳下一处);⌄ 改名/改类型/删除;＋ 批量补充。
- 改名旧写法自动转为别名,正文高亮不丢;非人实体改名全局生效(别的笔记跟着变)。
- 导出 MD 标题后新增「关键实体」一节。

## 播放:边听边逛

- **浏览其他会议不再打断播放**:右下角浮层继续管着,新页面点播放才切换声音;回到正在播的那篇仍从原位置续播。

## 修修补补

- 笔记列表按真实时刻排序:系统时区漂移(代理 IP 定位跑偏)期间录的笔记不再插错位。
- 试听「拆出/多人」有回执了,候选段彼此至少隔 20 秒——同一句话的碎片不再占满清单、拆完像没反应。
- 设置行不再被宽控件挤成竖排;侧栏页签排版中英各守其习(中文縦中横、英文书脊旋转)。

## 发布步骤(留档)

2. `gh release edit v0.17.0 --notes-file docs/releases/v0.17.0.md`,标题「v0.17.0 · 与会人员帮认人、关键实体清单、边听边逛」
3. 真机冒烟:有日程会议的名单指认与拼音中文名;无日程手动名单→重新推断;实体行编辑与定位;播放中逛别篇;从 0.16.0 一键更新
