# v1.1.0 发布说明

知识图谱能抽出人和事之间的关系了，身份推断的建议也能被采纳了；数据目录搬家不再把图谱弄空；本地识别引擎升级。

## 图谱里的「关系」和身份推断终于能出结果

- 以前 AI 整理时，让模型报出证据在原文第几个字到第几个字，模型数不准，只要一处对不上整篇的关系就全部作废——所以图谱里实体有、关系一直是 0；身份推断的建议也因为同一个原因一条都没被采纳过。
- 现在只让模型引用原话，位置由应用自己在原文里找；找不到的那一条丢掉，其余照常保留。
- 已有的笔记不会自动补上关系，需要对它点一次「AI 整理」（会重新调用大模型）。（#278）

## 密钥失效时立刻停下并告诉你

- 以前 API 密钥失效或模型名填错时，AI 整理会把每一段都试一遍、全部失败，笔记页只显示「部分失败」。
- 现在第一次被拒就停止整轮，笔记页直接提示是密钥被拒绝还是模型不存在，改好设置后点重试即可。（#278）

## 数据目录搬家不再丢图谱

- 以前在设置里迁移数据目录，只搬笔记和声纹，图谱里你确认过的改名、合并留在了旧目录，搬完图谱变成一篇笔记一堆孤立的点。
- 现在整个数据目录一起搬，以后新增的数据文件也不会再漏。（#276）
- 已经搬过家、图谱变空的不会自动恢复：只要旧目录还在，里面的 `knowledge-overrides.json` 就是丢掉的那份记录；找回脚本 `tools/restore-graph-ledger-847.sh` 需要从源码构建配套工具。
- 迁移和 AI 整理、关系补建不能同时进行：一边在跑时点另一边，会提示稍后再试。（#279）

## 本地识别引擎升级

- sherpa-onnx 从 1.13.4 升到 2.0.3。FireRedASR 识别速度约快一倍，其余本地引擎结果不变。（#275）

## 已知情况

- 新的关系与身份推断提示词只用历史记录离线回放验证过，还没有在真实笔记上跑过一轮；发布后第一件事就是验证它。
- 模型有时把「说话人」当成关系的一方，这类关系目前仍会被丢掉（约占离线回放里被丢弃的大半）。
