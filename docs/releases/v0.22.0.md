# v0.22.0 发布说明

v0.21.2 之后 6 个 PR：界面整体换新（三套皮肤）；会议中可以随手记备注；录音过程中也能给说话人选人、取消关联、删除；图谱页打开快了约 10 倍；AI 整理和 AI 助手接入支持 Pi；从终端直接启动时不再闪退。

## 界面换新

- 全部页面的按钮、开关、下拉、菜单、对话框统一换成一套组件，风格参照 shadcn：黑白灰配色、浅灰侧栏、内容区是浮起的白色圆角面板、白底描边卡片。页面布局没变。
- **三套皮肤**：经典、纸张、北境，每套都有浅色和深色，在「设置 → 皮肤」里和明暗分开选。启动时直接是上次的外观，不再先闪一下默认色。
- 弹出的菜单、确认框按 Esc 或点外面关闭时，不再连带关掉背后的抽屉、丢掉没保存的修改。
- 所有按回车提交的输入框，用中文输入法选字时按回车不会误提交。
- 迷你播放器的右键菜单从点击的位置弹出。（#265）

## 会议备注

- 录音时按快捷键（默认 ⌥⌘M）弹出一个小输入框，打一句话回车，就钉在当前录音时间点上，不打断录音。
- 录完后在笔记页正文旁看到这些备注，点一下跳到对应时间播放；可以补写、修改、删除，导出时一起带上。
- AI 整理会参考备注（只读，不改备注本身）。（#264）

## 录音中编辑说话人

- 录音过程中，说话人条上也能给说话人选人（关联声纹档案、从与会人员里一键指认）、取消关联、删除说话人，并显示每人说了几段；和录完后笔记页的做法一致。
- 删除的说话人，已经显示出来的段落会变回「未标注」，之后同一个人的新段落也不再归给他。
- 选人时声纹样本在停止录音后才写进声纹库（录音中声纹库不写）。录音中不提供试听：试听的声音会被录进去。（#726）

## 图谱打开更快

- 在实体多的资料库里，点开图谱从 2 秒多降到 0.2 秒左右，加载时窗口不再卡住。
- 默认只画「至少在 2 篇笔记里一起出现过」的连线；只在一篇笔记里碰到过的组合，点节点「展开」时才按需带出来，每点一次多 8 个。
- 在侧栏搜索里点中一个不在画布上的实体，会把它放上画布并带出邻居。
- 侧栏实体列表只列前 200 个（按出现篇数），更多的用搜索找。（#266）

## 其他

- **支持 Pi**：「AI 助手接入」多了 Pi，一键注册；AI 整理可以选 Pi 来跑。（#262）
- **从终端直接启动不再闪退**：从终端或 AI 助手里直接运行程序时，不再申请语音识别权限，避免被系统杀掉。（#263）

## 发布步骤（留档）

1. 发版前检查模型下载地址：`cargo test --manifest-path src-tauri/Cargo.toml --features devtools --lib -- --ignored every_registered_model_url_is_downloadable`。
2. `git tag v0.22.0 && git push origin v0.22.0` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
3. `gh release edit v0.22.0 --notes-file docs/releases/v0.22.0.md --title "v0.22.0 · 界面换新、会议备注、图谱提速" --draft=false --latest`（release.yml 产出的是草稿，不转正式一键更新看不到）。
4. 真机冒烟：
   - 从 0.21.2 一键升级。
   - 三套皮肤 × 浅色/深色；弹层 Esc / 点外面关闭；中文输入法回车。
   - 录音中按 ⌥⌘M 记备注；录完在笔记页看到、点击跳播、导出带上。
   - 录音中给说话人选人、删除；停录后声纹档案里有新样本。
   - 点开图谱的速度；展开节点；侧栏搜索点中实体。
