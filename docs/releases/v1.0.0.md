# v1.0.0 发布说明

Voice Notes 1.0。会议备注改成一篇 Markdown 文档，录音时和会后都在右侧一栏直接写，每一行自动带上录音时间；笔记页头部重新排布，更紧凑也更好找。

## 会议备注：一篇文档，每行带时间

- 录制页和笔记页右侧是通长一栏的备注文档，直接写就行，支持标题、列表、待办勾选框、加粗、引用、链接。
- 每个段落、标题、列表项在开始写字那一刻自动记下录音时间，显示在行左边；点一下滚到原文对应位置。会后写的新行：放过录音取当前播放位置，没放过沿用上一行的时间。改文字、改成标题都不改时间。
- 停手约 1 秒自动保存，没有保存按钮。录音中按 ⌥⌘M 记的一句会追加到文末；同时正在编辑别的行，两边都保留。离开页面时没存完的内容会先记在本机，下次打开这篇自动补回。
- 默认展开，可以收起成一条细轨（上面是各时间点的小点）；窗口窄时默认收起，录制页和笔记页各自记住。
- 原文里不再插备注小旗子；录制页底部的备注输入框去掉了（直接在右侧写）。删除就是删文字，⌘Z 撤销。
- 导出 Markdown / 文本时，开头多一个「备注」部分，原样保留你写的结构（列表层级、代码块），每行带时间。
- 老笔记的备注第一次打开时自动转成新格式，原文件改名为 `memos.json.bak` 留着，不删。（#269）

## 笔记页头部重新排布

- 第一行：标题，右侧「重新转文字」「AI 整理」和「⋯」更多（重新推断身份、导出、打开目录）。
- 第二行：时间与时长、日程、与会人员做成一排小胶囊，与会人员可直接加删。
- 第三行：播放条一张卡片——播放、回放音轨（双轨/成品轨）、备注、续录都在这里。
- 第四行：修订稿 / 原始逐字稿改成标签页，右侧显示整理或转文字进度。（#270）

## 发布步骤（留档）

1. 发版前检查模型下载地址：`cargo test --manifest-path src-tauri/Cargo.toml --features devtools --lib -- --ignored every_registered_model_url_is_downloadable`。
2. `git tag v1.0.0 && git push origin v1.0.0` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
3. `gh release edit v1.0.0 --notes-file docs/releases/v1.0.0.md --title "v1.0.0 · 会议备注改为 Markdown 文档、笔记页头部重排" --draft=false --latest`（release.yml 产出的是草稿，不转正式一键更新看不到）。
4. 真机冒烟：
   - 从 0.22.0 一键升级到 1.0.0。
   - 打开有旧备注的笔记：自动转换，内容与时间都对，目录里有 `memo.md` 和 `memos.json.bak`。
   - 录音中写几行（标题/列表/待办），时间对；点时间跳原文；中文输入法回车选字不误拆行。
   - 录音中按 ⌥⌘M 补一句，编辑器里实时出现；同时编辑别的行两边都在。
   - 切换笔记、离开页面后再回来，刚写的字都在。
   - 导出 md/txt 开头有「备注」部分。
   - 笔记页头部：宽窗/窄窗排布、「⋯」菜单、回放音轨切换、续录、标签页。
