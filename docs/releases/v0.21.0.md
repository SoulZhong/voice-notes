# v0.21.0 发布说明

v0.20.0 之后 3 个 PR：设置页加简洁模式；一键更新和模型下载在慢网下不再半途失败，按需自动换到加速线路；录音时菜单栏小姑娘的书写动作更明显。

> **从 0.20.0 升级的提示**：这一次升级仍由 0.20.0 的旧代码下载。网速较慢时，一键更新可能还会在半途报失败；遇到这种情况，请点「打开发布页」手动下载安装一次，以后的升级就不会再有这个问题。

## 简洁模式

- 设置页最上面新增「显示全部设置」开关。关掉后只显示常用设置：外观、语言、快捷键、开机启动、匿名统计、音频占用与清理、日历匹配、会后 AI、关于与更新。
- 识别方式和语音模型在简洁模式里各变成一行状态，比如「本地 · SenseVoice」「已就绪」；缺少录音必需的模型时，直接给出「下载」按钮。
- 被隐藏的设置保持原值，照常生效。切换模式不会改动任何设置。
- 简洁模式下，左侧菜单不显示「钩子」；「设备」只在连接过 AI Passport 设备后显示。
- **新安装默认简洁模式**；从旧版升级的用户保持原来的完整模式。首次引导时点「高级设置」的，会直接进入完整模式。

## 下载更稳

- **一键更新不再半途失败**：以前整个升级包必须在 30 秒内下完，网速每秒不到约 0.85 MB 时，进度条走到一半就报「升级失败」。现在只有连续一段时间收不到数据才算失败，并且断了能从已下载的地方接着下。
- **下载线路自动选择**：模型和升级包都是先直连 GitHub；连不上、卡住或持续太慢，就自动换到国内加速镜像接着下，进度旁会提示「网络较慢，已切换加速线路」。下次优先用上次成功的线路。
- 设置里的「镜像加速」开关去掉了，完整模式下改为显示当前的下载线路。
- 神经回声消除（DTLN）模型的下载地址恢复：此前一段时间这两个模型下载会失败。

## 其他

- 录音时，菜单栏的小姑娘握笔划写的动作更明显，一眼能看出在录；帧率不变，不增加耗电。
- 设备页「去授权」（语音识别）在系统没有弹出授权框时，会直接打开系统设置的对应页面。

## 发布步骤（留档）

1. 发版前检查模型下载地址：`cargo test --manifest-path src-tauri/Cargo.toml --features devtools --lib -- --ignored every_registered_model_url_is_downloadable`。
2. `git tag v0.21.0 && git push origin v0.21.0` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
3. `gh release edit v0.21.0 --notes-file docs/releases/v0.21.0.md`，标题「v0.21.0 · 简洁模式、下载更稳」。
4. 真机冒烟：
   - 全新安装（清空开发版数据）走首次引导 → 默认简洁模式；点「高级设置」出口 → 完整模式。
   - 从 0.20.0 升级后保持完整模式；切到简洁模式再切回，设置值不变。
   - 限速或断开直连时，模型下载切到加速线路并出现提示。
   - **下一次发版时**，从 0.21.0 一键升级（新的下载逻辑要从这一版开始才生效）。
   - 录音时菜单栏动画。
