# v0.19.0 发布说明

v0.18.0 之后 12 个 PR：macOS 上新增省电的「Apple 原生」识别引擎；停止录音改为立即停止；修了托盘菜单的一处崩溃和三处让自动认人无从撤销的回归；认人和笔记页里的大段逻辑拆成了能单独测试的模块。

## Apple 原生识别：省电档（macOS 26+）

- 设置 →「识别引擎」第一位新增「Apple 原生」，调用 macOS 自带的语音识别，跑在神经网络引擎上。
- 实测 10 分钟中文会议：CPU 时间 1.8 秒（SenseVoice 70 秒），内存 140MB（1.3GB）。中文准确率和 SenseVoice 同档、互有胜负，标点偏少。
- 只在 macOS 26 及以上显示。全新安装时默认选它，老用户原来的选择不动；Windows 和更早的 macOS 默认仍是 SenseVoice。
- 中文语言包由系统下载和管理：欢迎页点「下载」会顺带装好，设置页也有单独的下载按钮。

## 录制

- **立即停止**：点停止后界面立刻呈现「已停止」（计时定格、开始钮复位），不再显示数秒的「正在停止…」。采集本来就是第一时间关闭的，等待的只是最后几句的识别和换人切分，现在放到后台完成，内容不丢，收尾后照旧跳转笔记。托盘、快捷键、MCP 发起的停止同样立即生效。
- **修：托盘菜单偶发崩溃**：托盘菜单在状态变化时会整份重建；若重建时恰好开着菜单并点了某一项（如停录收尾时点「打开主窗口」），应用会直接退出。现在换下的菜单会保留一段时间再释放。

## 认人

- 修：自动认人的回执**永远没有「撤销」按钮**，还误报「关联已被改动」。
- 修：已经手动关联的说话人还在反复弹识别建议。
- 修：崩溃发生在“关联已写、进度未记”的那一刻时，回执会消失，但关联其实已经生效，没法撤销。
- 笔记被占用时，拒绝提示会点名是谁在占用（录制 / AI 整理 / 重新转文字 / 生成成品轨），不再只说“稍后再试”。

## 工程（架构评审 7 项全部落地）

说话人表、声纹模型空间、修订稿同步、笔记占用准入、拆分状态机、认人主干、识别建议、后台任务订阅，各自收成一个模块，并补上整链特征测试。用户侧行为不变（上面列出的修复除外）。

## 发布步骤（留档）

1. `git tag v0.19.0 && git push origin v0.19.0` → release.yml 产出 dmg/exe/updater（约 20 分钟）。macOS 构建要求 macOS 26 SDK（`VN_REQUIRE_APPLE_ASR`），runner 镜像 macos-26-arm64 满足。
2. `gh release edit v0.19.0 --notes-file docs/releases/v0.19.0.md`，标题「v0.19.0 · Apple 原生省电识别、立即停止」
3. 真机冒烟：签名版首次用 Apple 原生是否弹语音识别授权；全新安装默认选中、欢迎页一并装语言包；开录实时出字；用 Apple 原生重转写；自动认人回执出现「撤销」；录制页/侧栏/托盘/快捷键停止均立即呈现已停止、末尾几句不丢；停录收尾时开着托盘菜单点「打开主窗口」不崩；从 0.18.0 一键更新后老用户引擎不变
