# v0.21.1 发布说明

v0.21.0 之后 1 个 PR：只来开过一两次会的外部客户，不会再在他没来的会里被认出来。

## 认人更准

- **只来过一两场的人，认人更谨慎**：以前一位客户只来开过一次会，之后别的会上有人在差不多的会议室里、离麦克风远远地说话，常被认成他。原因是他的声纹只从一两场会里学到，连那间屋子、那支麦克风的声音特点一起记了下来。现在按声纹样本来自几场会分档：1 场的要更像才认（门槛 0.78），2 场的 0.74，3 场及以上不变（0.68）。
- **整组并入也一样严**：会中把一整组没认出来的发言并进某个人时，也按他的档位来，不再走旧门槛。
- **真来了却没认出来**：在笔记里点一次他的名字，他就多了一场的样本，下次的门槛会自动降一档。
- 拿 9 月以来的 117 场会回放：错认出某人的次数从 124 次降到 55 次，认对的从 236 次降到 229 次。

## 发布步骤（留档）

1. 发版前检查模型下载地址：`cargo test --manifest-path src-tauri/Cargo.toml --features devtools --lib -- --ignored every_registered_model_url_is_downloadable`。
2. `git tag v0.21.1 && git push origin v0.21.1` → release.yml 产出 dmg、exe 和升级包（约 20 分钟）。
3. `gh release edit v0.21.1 --notes-file docs/releases/v0.21.1.md`，标题「v0.21.1 · 外部客户不再被乱认」。
4. 真机冒烟：
   - 从 0.21.0 一键升级（新的下载逻辑从 0.21.0 起生效，这是第一次实测）。
   - 录一场有内部同事的会，确认只来过一两场的外部人不再被认出；常来的同事照常认出。
