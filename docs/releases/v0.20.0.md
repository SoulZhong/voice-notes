# v0.20.0 发布说明

v0.19.0 之后 3 个 PR：AI Passport 设备听写并入 Voice Notes（macOS 和 Windows）；全面省电；录音时实时字幕改用流式识别。

## 设备听写（AI Passport）

- 左侧新增「设备」菜单。用刷了 [VibeVoice](https://ai-passport.folotoy.cn/plays/965/?v=2126-2) 的 [AI Passport](https://ai-passport.folotoy.cn/) 设备说话，文字直接插入 Orca、ChatGPT（Codex）、微信、企业微信当前的会话。
- 功能与原来独立的 VibeVoice 程序一致：跟随你切换的会话、插入、发送、撤销，长按 OK 跳到会话，Orca 里 Agent 干完活时设备上提醒，双击 OK 开始或停止 Voice Notes 录音。
- **Windows 首次支持**：在 Voice Notes 里输入设备屏幕上的 6 位配对码完成配对；识别用本机模型，说话时设备屏上实时出字，说完整句再识别一遍。
- macOS 优先用 Apple 语音识别（带热词）；没有语音识别权限时改用本机模型。辅助功能和语音识别权限各有「去授权」按钮，点一下就会打开对应的系统设置页。
- **听写笔记**：每次插入的文字按会话归档到笔记列表，撤销过的句子划线显示。文字默认保存；音频默认不存，开启后保留 30 天。AI（MCP）默认读不到听写内容，需要在设置里打开。
- 设备固件与 Voice Notes 版本对不上时，会明确提示该刷固件还是该升级 Voice Notes。
- 不用设备的话，在设置 › 通用里关掉「设备」，菜单就会隐藏。
- 独立的 VibeVoice 程序不再维护。它和 Voice Notes 同时运行时，Voice Notes 会提示你先退出它。

## 省电

- **打开笔记不再阻止 Mac 睡眠**：以前只要打开过一篇笔记，播放器就一直占着声卡（暂停时也在播静音），Mac 无法自动进入空闲睡眠。现在只在真正播放时才占用声卡。
- **录音时实时字幕改用流式识别**：使用 SenseVoice 等本机模型时，字幕不再每秒把整句从头重识别一遍。实测录音时 CPU 降到原来的约 1/4，每句的最终文字不变。需要「实时字幕（流式识别）」模型：识别引擎不是 Apple 的新安装会默认下载，老用户可在设置的模型列表里下载；没下载时字幕照常显示，每 2 秒刷新一次。Apple 原生引擎和云端识别不受影响。
- 设备连着时查询 Orca 的频率按需放慢（每分钟 59 次降到约 6 次）。
- 输入音量检测不再每 4 秒启动一个脚本进程；窗口隐藏时也不再检测。
- 录音时菜单栏图标动画降帧；窗口隐藏时不再推送电平；两个后台线程空闲时不再定时唤醒。

## 发布步骤（留档）

1. `git tag v0.20.0 && git push origin v0.20.0` → release.yml 产出 dmg/exe/updater（约 20 分钟）。
2. `gh release edit v0.20.0 --notes-file docs/releases/v0.20.0.md`，标题「v0.20.0 · AI Passport 设备听写、省电」。
3. 真机冒烟：
   - Windows 同事：配对码配对、往 Orca、ChatGPT、微信听写、发送、撤销，双击 OK 录音（清单见 PR #250）。
   - macOS：从 0.19.0 一键更新后，「设备」菜单出现；连接设备并听写。
   - 打开笔记后 `pmset -g assertions` 里没有 coreaudiod 的 audio-out；播放、暂停、拖动进度正常。
   - SenseVoice 录音时实时字幕的开头完整、定稿替换正常；外放时「我」那一行不跟读对方。
4. 发布后：删掉固件仓库（vibe-voice-input）里的 `host/` 目录；之后发布固件时在说明里附上 Voice Notes 的下载地址。
