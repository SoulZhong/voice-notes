# v0.16.0 发布说明

v0.15.0 之后 13 个 PR:音轨能删减了,现场会的"分人"从算法到交互修了一整条线,改名終於等于指认。

## 音频删减:掐掉不要的,随时反悔

- 圈选游标圈住一段 → 播放器下方「删除圈内这段」:播放自动跳过、导出文本/音频自动剔除、逐字稿灰显加删除线。
- **非破坏性**:原始录音一个字节不动,删的只是一条剪辑表;「已删 n 段」管理浮层里逐段恢复/全部恢复,刚删的 10 秒内可一键撤销。
- 试听说话人时临时绕过删减(试听是"听清是谁",不该被跳段跳成无声)。

## 现场会分人:从"每段都是俩人"到能用

- **段内换人检测起死回生**:切分器早已存在,但绝对阈值对现场录音全瞎(同房间底纹把窗间相似度抬到 0.85,实测 950 对相邻窗只触发 7 次)。改自适应低谷(相对段内自身基线找凹陷),真实会议标定:49 个长段切出 65 个换人点,平均 1.3 个/段,无碎片化。新录制与「重新分析」都受益。
- **试听候选按"区分度"排序**:像本簇 − 最像的他簇。多人混杂段对两边都像,自动沉底;纯净段浮顶。
- **「多人」标记**:实在分不开的段一键标记为多人——不归任何人、不造假说话人、文字保留,徽章显示中性灰「多人」。
- 试听行三枚带字胶囊:**＋样本**(纯净段入库)/**拆出**(是另一个人)/**多人**(分不开);不再靠图标猜。
- 现场会里没声纹的短段兜底徽章从「我」改「未识别」——不再把别人的话安到你头上。

## 改名就是指认

- **手动标题最高优先级**:AI 自动标题只在"仍是默认名"时写入,判定与写入同锁——Aing 跑几十分钟期间你改的名不会再被收尾覆盖。
- **改说话人名字 = 指认这是谁**:已关联库人物的说话人改成不同名字时,自动解除旧关联(退还溯源样本)并按命名即入库重新建档/关联;不再出现"界面叫陈伟丹、库里还挂着曾老师"的分叉。
- 导出取名与界面同序(本地改名压过库名);修订稿徽章随改名即时刷新,不用切视图。

## 其它

- **Aing 中可以继续录制**:录制优先,在跑的整理降级为可弃稿,停录后自动全量重跑。
- 「重新分析」显性入口:重转写按钮从纯图标升级为带文字胶囊——切段/识别算法升级后,旧笔记靠它受益。
- 重转写期间改名会明说原因(此前只报"被占用")。
